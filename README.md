# Proyek Pemrograman Mobile

## Deskripsi

Aplikasi latihan Flutter untuk memenuhi praktikum Pemrograman Berbasis Mobile. Proyek ini merupakan aplikasi awal yang dibuat menggunakan Flutter sebagai bagian dari proses pembelajaran pengembangan aplikasi mobile.

## Status

Proyek awal perkuliahan.

## Tujuan
Proyek ini bertujuan untuk mempelajari dasar-dasar pengembangan aplikasi mobile menggunakan Flutter serta menerapkan penggunaan Git dan GitHub dalam pengelolaan versi proyek.

## Rencana Fitur
- Menampilkan halaman utama aplikasi.
- Menambahkan fitur dan tampilan sesuai kebutuhan pembelajaran.
- Mengembangkan aplikasi secara bertahap menggunakan Flutter.

## Cara Menjalankan
